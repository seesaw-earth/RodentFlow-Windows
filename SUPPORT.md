# Support: RodentFlow for Windows

*[简体中文见下方](#支持rodentflow-windows-版)*

## Report a problem or ask a question

Open an issue: **[github.com/seesaw-earth/RodentFlow-Windows/issues](https://github.com/seesaw-earth/RodentFlow-Windows/issues)**

Please include:

1. **Version** of RodentFlow and of Windows, and the graphics card if the problem concerns analysis speed.
2. **Task** (open field, elevated plus maze …) and whether one or two mice are tracked.
3. **What you did, what you expected and what happened**, with the exact error message.
4. If the app does not start: the contents of `%LOCALAPPDATA%\RodentFlow\startup-error.log`.
5. If it concerns tracking: a screenshot of the preview and, if you are allowed to share it, a short clip.

GitHub issues are public. Do not post unpublished data, identifiable information, or videos you are
not allowed to share. For a sensitive question, open an issue asking only for a private contact
channel, without the details.

The user manual of RodentFlow (Mac, iPhone and iPad) is at
[seesaw-earth.github.io/RodentFlow](https://seesaw-earth.github.io/RodentFlow/); the assays, measures
and statistics are the same on Windows.

RodentFlow collects no data; see the [privacy policy](PRIVACY.md).

# 支持：RodentFlow Windows 版

## 报告问题或提问

请提交 issue：**[github.com/seesaw-earth/RodentFlow-Windows/issues](https://github.com/seesaw-earth/RodentFlow-Windows/issues)**

请写明：

1. RodentFlow 和 Windows 的**版本**；如果问题与分析速度有关，再写显卡型号。
2. **任务**（旷场、高架十字迷宫……），以及追踪一只还是两只小鼠。
3. **你做了什么、预期是什么、实际发生了什么**，附上完整的错误信息。
4. 如果 App 无法启动：附上 `%LOCALAPPDATA%\RodentFlow\startup-error.log` 的内容。
5. 如果与追踪有关：预览截图；如果允许分享，再附一小段视频。

GitHub issue 是公开的。不要发布未发表的数据、可识别身份的信息或你无权分享的视频。涉及敏感问题时，请只提交一个请求私下联系的 issue，不要写具体内容。

RodentFlow（Mac、iPhone 和 iPad）的使用手册见
[seesaw-earth.github.io/RodentFlow](https://seesaw-earth.github.io/RodentFlow/zh/)；Windows 版的实验范式、指标和统计与之相同。

RodentFlow 不收集任何数据，见[隐私政策](PRIVACY.md)。
